# 애플리케이션 보안 솔루션 운영 (학습 1-2)

## 설치 (<표 1-6>, p.12)

설치 전(권장 사양, 설치 매뉴얼의 유의사항) → 설치 중 → 설치 후(정상 설치 확인, 환경설정·문서화).

## 운영 점검 (p.12)

1. 점검 체크리스트를 확인한다.
2. 항목별로 점검하고 결괏값을 적는다.
3. 이상이 있으면 항목의 중요도와 조치 기준에 따라 조치한다.

| 항목 | 점검 방법 | 취약 판단 기준 (<표 1-8>) |
|---|---|---|
| 디렉터리 인덱싱 | 경로를 URL로 직접 입력 | 디렉터리·파일 목록이 보이면 취약 |
| 관리자 페이지 노출 | admin, manager, webmaster 등 추측 경로 접근 | 관리자 페이지가 열리면 취약 |
| 백업 파일 노출 | 추측 가능한 백업 파일명 접근, 인덱싱으로 확인 | 백업 파일이 내려받아지면 취약 |
| 웹 서비스 메소드 | PUT, DELETE 등 요청 | 허용되면 취약 |

랩: WAF 상태는 `waf_config`(엔진 모드, 패러노이아 레벨, 임계값, 예외 규칙), 이벤트는 `waf_events`.
엔진이 탐지 전용(DetectionOnly)이면 '운영 중'이어도 막지 않는다는 점을 점검 결과에 적는다.
