# 업데이트 계획 수립 (학습 4-1)

## 패치 관리 절차 9단계 (p.68, [그림 4-2])

1. 신규 업데이트 정보를 수집한다.
2. 업데이트 대상 솔루션 목록을 작성한다.
3. 목록 기준으로 제조사가 제공하는 패치 업데이트 방법을 정리한다.
4. 최근 공개된 취약성과 패치 내용을 검토한다(`vuln_feed`).
5. 시스템 환경과 구성 설정을 분석한다(`package_inventory`, `host_config`).
6. 패치 적용 계획을 수립한다.
7. 패치 테스트를 수행한다.
8. 계획에 따라 패치를 수행한다.
9. 이상 유무 확인을 위해 시스템을 모니터링한다.

24시간 무중단 장비는 이중화 절체 순서, 적용 시간대, 실패 시 즉시 복구 경로를 계획에 넣는다.
패치 시스템 자체도 공격 대상이 될 수 있으므로 패치 파일의 출처·무결성을 확인한다(<표 4-1>).
