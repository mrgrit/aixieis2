# 업데이트 적용 (학습 4-2)

## 절차 ([그림 4-4])

1. **백업 계획을 세우고 먼저 백업한다.** (p.59) 백업 형태·범위, 주기를 정하고 수행한다.
2. **복구 계획과 복구 매뉴얼을 쓴다.** (p.59) 롤백 조건(무엇이 보이면 되돌리나)을 숫자로 적는다.
3. **영향도를 고려해 시험 패치를 한다.** (p.59)
4. **업데이트를 수행한다.** (p.60) 승인된 변경만 `change_apply`.
5. **서비스 정상 여부를 모니터링한다.** (p.60) 결과를 업무 담당자에게 통보하고, 장애가 나면 복구한다.

## 적용 보고서

1. 적용 배경·목적 2. 진행 절차 3. 적용 후 확인 결과(무엇을 어떻게 봤는지) 4. 문제 발생 여부와
조치 5. 최종 결론과 향후 계획. 확인하지 않은 항목은 '확인함'으로 쓰지 않는다.
