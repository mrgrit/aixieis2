# 위험 평가 방법 및 보호 대책 파악 (학습 1-2)

## 절차

1. 자산을 식별하고 중요도를 평가한다. (pp.16-17)
2. 기존 정보 보호 대책을 점검한다. (p.18) 정책·계획·대책 목록 확인 → 보호 담당자 면담 → 현장 확인 →
   가능하면 기술적 점검·침투 시험. 대책 현황 명세서를 쓴다(<표 1-12>).
3. 위협과 취약성을 평가한다. (p.19)
4. 위험도를 평가한다. (p.20)

   | 자산 중요도 \ 발생 가능성 | 높음 | 보통 | 낮음 |
   |---|---|---|---|
   | 높음 | 매우 높음 | 높음 | 보통 |
   | 보통 | 높음 | 보통 | 낮음 |
   | 낮음 | 보통 | 낮음 | 매우 낮음 |

5. 목표 위험 수준을 정한다. (p.21) 위험 우선순위를 정하고, 수용 가능한 위험 수준을 결정한다.
6. 보호 대책을 선택한다. (pp.23-26) 필수 대책 → 자산 종류별 대책 → 자산별 발생 가능성·위험도 → 자산별 대책.

## 위험 분석 방법론 고르기

| 방법론 | 언제 고르나 |
|---|---|
| 기준선(베이스라인) | 모든 자산에 같은 기본 대책. 빠르고 싸지만 조직 특성 미반영 |
| 비정형 | 전문가 경험으로 빠르게. 소규모, 구조화 어려움 |
| 상세 위험 분석 | 자산 가치·위협·취약성을 정밀 분석. 근거가 명확, 비용 큼 |
| 복합 | 중요 자산은 상세, 나머지는 기준선. 예산·인력이 부족하면서 중요 자산은 정밀히 봐야 할 때 |

"중요한 자산은 정밀하게, 덜 중요한 자산은 기본 수준에서"라는 요구에는 복합 접근법이 맞다.
