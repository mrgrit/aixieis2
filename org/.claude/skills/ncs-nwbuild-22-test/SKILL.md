# 네트워크 보안 테스트 (학습 2-2)

## 계획 (pp.61-62)

1. 테스트 범위와 항목을 정의한다.
2. 테스트 환경과 일정을 정의한다.
3. 테스트 계획서를 작성한다.

## 시험 (p.63)

1. 라우터·스위치 등 네트워크 시험.
2. 네트워크 장비 보안 시험(계정, 접근, 불필요 서비스).
3. 서버 네트워크 영역의 보안 장비·솔루션 시험.
4. 클라이언트 네트워크 영역의 보안 장비·솔루션 시험.
5. 네트워크 보안 운영관리 시스템 시험.

정책 시험은 '허용돼야 할 연결'과 '막혀야 할 연결'을 짝으로 만든다(`x-change-verify`).

## 재평가 보고서

개요·목적 / 테스트 환경·도구 / 문제 구간과 원인(예: 로그 누락) / 적용한 개선(기술적·관리적) / 재평가 결과 /
잔여 위험과 후속 조치.
