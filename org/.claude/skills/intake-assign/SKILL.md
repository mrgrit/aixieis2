# 접수와 배정

## 분류 → 담당

| 요청 유형 | 담당 |
|---|---|
| 경보 판정, 로그 분석, 타임라인, 탐지 패턴 | soc-analyst |
| 방화벽·IPS·VPN 정책, 네트워크 차단·업데이트 | nw-sec-ops |
| WAF 정책, 웹 공격 차단, 과차단 | app-sec-ops |
| 서버 점검·패치·백업·서버 위협 | sys-sec-ops |
| 새 서버·DB 보안 설계·구현 | sys-sec-build |
| 망 설계, 구간 분리, 정책표 설계 | nw-sec-build |
| 소스코드 약점, 시큐어 코딩 | sw-sec-dev |
| 취약점 진단, 위험 평가, 조치 계획 | diag-consultant |
| 침해사고 전체 조정, 격리 | cert-coordinator |
| 승인 | ciso |
| 실행 증적 확인 | auditor |

## 절차

1. 요청에서 대상(자산), 증상, 시각, 요청자가 원하는 결과를 뽑는다. 빠진 정보는 질문으로 남긴다.
2. 표로 담당을 고른다. 여러 직무면 의존 순서(예: 판정 → 차단 → 복구)를 정한다.
3. `handoff_request`로 넘긴다. 요청서에 대상, 증상, 기대 산출물, 기한을 적는다.
4. 배정한 것과 처리된 것을 구분해 보고한다.
