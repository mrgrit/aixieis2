# 네트워크 보안 위협 차단 (학습 3-1)

## 절차

1. **외부로 연결된 망을 점검한다.** (p.40) 외부에서 접근 가능한 모든 시스템, 외부 관문 라우터와 방화벽 기능.
2. **내부 망을 점검한다.** (p.40) 백도어 여부, 내부 사용자·게스트로부터의 내부 시스템 보안.
3. **내·외부 점검 항목으로 위협을 점검한다.** (p.41)

   | 항목 | 외부 | 내부 |
   |---|---|---|
   | Whois | ○ | |
   | DNS 질의, SNMP 데이터, 호스트 식별, 포트 스캐닝(TCP/UDP) | ○ | ○ |
   | 네트워크 파일 공유(NFS, SMB, FTP, TFTP), 네트워크 취약점, 네트워크 장비 | ○ | ○ |
   | 방화벽 점검 | ○ | 필요시 |

4. **차단 정책을 준비한다.** 근거(관제 분석 결과·로그)를 확인한 뒤에만 차단한다. 근거 없는 차단은
   정상 업무를 끊고 증거 수집을 망친다.
   - 방화벽: 출발지(악성 IP·점거 PC)와 대상(관리 포트 등)을 최소 범위로 지정한 차단 규칙을 **허용
     규칙보다 위에** 둔다.
   - IPS: 해당 공격 시그니처를 탐지에서 차단 모드로 올리거나, 비인가 접근 탐지 시그니처를 강화한다.
   - 보호 정책 예: 관리 포트(SSH·Telnet) 접근을 관리자 전용망으로만 제한.
5. `change_prepare`(kind=fw/ids/containment) → 승인 → 적용 → 같은 공격 패턴 로그가 더 나오지 않는지 확인.
