# 업데이트 적용 (학습 4-2)

## 적용 (pp.52-53)

1. 운영과 같은 환경에서 사전 테스트한다. 기한 내 해결 안 되는 오류가 있으면 일정을 미룬다.
2. 테스트가 성공하면 사전 공지 담당을 통해 공지한다.
3. 계획서의 복구 시점에 맞춰 데이터를 백업해 별도 저장소에 둔다.
4. 계획된 시간에 패치를 적용한다(필요하면 서비스 중단).
5. 업데이트가 정상 적용됐는지, 솔루션이 정상 작동하는지 확인한다.
6. 중단한 서비스를 재시작 순서대로 재기동한다.
7. 재기동한 서비스가 정상인지 확인한다.
8. 전체 서비스 정상 확인 후 결과 보고서를 쓴다(<표 4-3>).

## 실패 시 (p.54)

5에서 정상 적용이 안 되면: 백업 데이터로 **롤백** → 재기동 순서대로 재기동 후 정상 확인 → 원인·문제점
분석 보고서 → 원인을 반영해 업데이트 계획 재수립.

시험 문항5의 순서: 기존 설정 백업 복원 → 서비스 상태 확인 → 검증 후 재적용.
