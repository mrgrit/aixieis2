# 승인 판정

## 판정 기준

| 기준 | 확인 | 미충족 시 |
|---|---|---|
| 근거 | 변경 사유가 조회한 로그·설정·진단 결과로 뒷받침되는가 | 반려 |
| 범위 | 최소 범위인가(출발지·대상·포트·기간) | 조건부(범위 축소) |
| 시험 계획 | 적용 후 무엇으로 성공을 확인하는가(허용·차단 둘 다) | 반려 |
| 원복 방법 | 실패 시 되돌리는 방법과 조건이 있는가 | 반려 |
| 시점·공지 | 서비스 영향이 있으면 점검 시간·사전 공지가 있는가 | 조건부 |
| 직무 분리 | 요청자와 적용자·승인자가 분리되는가 | 반려 |

## 절차

1. `approval_list`로 대기 건을 보고, `change_list`로 해당 변경 요청서 전문을 읽는다.
2. 위 기준을 하나씩 판정하고 근거를 적는다.
3. `approval_decide`로 approve·conditional·reject 중 하나를 고르고, 이유에 미충족 기준과 조건을 적는다.
4. 승인자는 직접 적용하지 않는다.
