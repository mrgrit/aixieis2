# 복구 및 문서화 (학습 3-2)

## 준비 (p.39)

복구 체크리스트, 복구 절차서, 백업 파일 목록과 주기적 백업.

## 복구 (p.39)

1. 백업 파일로 복구한다(설정 롤백).
2. 서비스를 재기동한다.
3. 정상 서비스 동작을 확인한다(정상 사용자 요청이 통과하는지, 차단해야 할 공격이 여전히 막히는지 둘 다).

## 문서화 (p.40)

1. 보안 위협, 영향, 조치 내용을 정리한다.
2. 서비스 중단의 원인과 문제점을 분석한다. 과차단이면 어떤 규칙이 어떤 정상 요청에 걸렸는지
   (규칙 ID, 요청 경로, 매칭 값)를 로그로 확인한다.
3. 결과 보고서를 쓴다(<표 3-9>): 서비스 장애 개요 / 중단 내용·원인 / 영향도 분석 / 조치 사항 / 재발방지 대책.

과차단 뒤의 정책 수정은 `x-crs-fp-tuning`의 최소 범위 예외 원칙을 따른다.
