# 탐지패턴 최적화 (학습 3-2)

목표: 개발된 탐지패턴의 적용 여부를 판단하고 최적화 방안을 도출한다.

## 절차

1. **패턴을 적용한다.** (p.78) 장비 운영 조직·책임자와 협의해 적용 일정을 잡는다. 분석가는 직접
   적용하지 않고 운영 담당에게 넘긴다.
2. **일정 기간 모니터링해 평가한다.** (p.78) 모니터링 기간과 평가 기준을 먼저 정하고, 기준에 따라 평가한다.

   | 항목 | 만족 기준 (<표 3-14> 사례) |
   |---|---|
   | 오탐률 | 전체 탐지 건수의 1% 이하 |
   | 정탐률 | 동일·유사 탐지 건수의 95% 이상 |
   | 리소스 사용률 | 현행 수준 유지(±1%) |
   | 탐지 성능 | 현행 수준 유지(±1%) |

   기준값은 조직이 정한다. 위 값은 학습모듈의 사례이며, 조직 기준이 있으면 그것을 먼저 쓴다.
3. **지속 여부와 개선 여부를 판단한다.** (p.80) 이해관계 부서를 확인하고, 평가 결과로 적용
   지속 여부를 정하고, 지속한다면 개선이 필요한지 정한다.
4. **최적화 방안을 도출한다.** (p.83) 개선 가능한 영역(조건·범위·표현식)을 찾고, 장비의 탐지
   메커니즘을 확인해 개선 범위를 정한다.
5. **패턴을 개선한다.** (p.84) 기존 패턴을 영역별로 나누고, 개선할 영역을 치환하고, 다시 합친다.
6. **개선된 패턴을 적용한다.** (p.84) 1단계와 같이 운영 담당에게 넘긴다.

## 산출물

| 항목 | 기준 | 측정값 | 평가 |
|---|---|---|---|

결론에 '지속·개선·중단' 중 하나와 이유를 적는다. 측정값이 없으면 평가하지 않고 '측정 불가'로 둔다.
