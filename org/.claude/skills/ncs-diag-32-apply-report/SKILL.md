# 보호 대책의 적용 (학습 3-2)

## 절차

1. 정보 보호 대책을 작성한다. (p.77, <표 3-15>)
2. 분야별 조치 내역을 작성한다. (pp.78-80) 서버(<표 3-16>), 네트워크(<표 3-17>), 애플리케이션(<표 3-18>), DB(<표 3-19>).
   - 진단 담당은 조치 요청서를 담당 직무에 넘긴다: 서버 `sys-sec-ops`, 네트워크 `nw-sec-ops`,
     WAF `app-sec-ops`, 코드 `sw-sec-dev`. 넘긴 ID를 조치 내역에 적는다.
3. 취약점 진단 결과를 작성한다. (p.80, <표 3-20>)
4. 조치 결과 보고서를 작성한다. (p.81, <표 3-21>) 조치하지 않은 항목은 위험 수용 근거와 함께 남긴다.

## 기술적 보호 대책 예

- 접근 통제: 관리자 페이지에 접근 가능한 IP를 관리망으로 제한(WAF·방화벽), 추가 인증.
- 소스코드·경로: 관리자 기능을 일반 사용자 인터페이스와 분리, 추측하기 어려운 경로 사용, 로그인 시도 제한.
