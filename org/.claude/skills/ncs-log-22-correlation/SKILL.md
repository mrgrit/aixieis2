# 상관분석 (학습 2-2)

목표: 타 보안장비와 시스템 로그를 활용한 상관분석으로 공격의 정확한 경로와 히스토리를 분석한다.

## 절차

1. **오탐·정탐 판정 기준을 확인한다.** (p.48) 탐지 기준 지침의 판정 내용을 찾는다(`policy_docs`).
2. **탐지된 이벤트를 판정 기준과 비교해 판정한다.** (p.49)
   - 기준 예(<표 2-22>): 2개 이상의 정보시스템·보안시스템에서 동일·유사 이벤트가 탐지되고,
     자산 손실·파손·비인가 변경이 확인되면 정탐으로 판단한다.
3. **공격 경로를 파악한다.** (p.50) 공격자 주소를 확인하고 경로를 분석해 도식화한다
   (랩: `network_topology`, kt66 웹 경로는 ext → fw → ips → web(WAF) → 앱).
4. **피해 유무를 파악한다.** (p.51) 공격 대상 시스템과, 그와 연계된 시스템의 피해를 조사한다.
5. **보안이벤트를 모으고 상관분석한다.** (pp.52-53)
   - 탐지한 시스템별로 이벤트를 수집한다.
   - 연관성(시간 순서·같은 출발지·같은 대상)을 조사한다. 예) 방화벽 허용 13:58:10 → 5초 뒤 IPS BOF 탐지.
   - 공격 방법·범위·피해 정도를 확인하고, 침해공격 목적과 공격 수준을 도출해 **침해 시나리오**로 통합한다.
6. **공격 경로를 도식화한다.** (p.54) 전체 흐름(Flow) → 노드 → 노드별 항목 → 노드별 Action·특이사항.
7. **공격 히스토리와 비교한다.** (pp.54-55) 과거 침해 이력(`incident_history`)에서 같은 경로 노드·
   출발지·기법이 있는지 확인하고, 일회성인지 지속 위협인지 **공격 동향**을 판정한다.

## 산출물

| 시각 | 시스템 | 출발지 → 목적지 | 이벤트 | 해석(단계) | 근거 |
|---|---|---|---|---|---|

- 침해 시나리오: 누가(Who) / 어디로(Where) / 어떻게(How) / 왜(Why)
- 최종 타깃 시스템과 피해 내용, 공격의 성격(일회성 / 지속 위협)과 향후 대응 방향
- 수집하지 못한 장비·기간(미탐 후보와 수집 누락을 구분)

## 유의 (p.55 tip)

경로·히스토리 분석 결과는 분석자에 따라 달라질 수 있다. 연결의 근거(시각 차이, 같은 IP·대역, 같은 대상)를 한 줄씩 적는다.
