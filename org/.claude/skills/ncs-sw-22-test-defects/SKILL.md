# SW개발 보안 테스트와 결함 관리 (학습 2-2)

## 테스트 (pp.67-70)

1. 시험 단계를 수행한다(보안 기능 시험 절차).
2. 취약점 테스트 주기와 대상을 정한다. 점검 팀이 개발 팀에 요청하고 범위·비용·일정을 합의한다.
3. 변경 요청과 일정을 세운다. PM과 점검 팀이 직접 협업하고, 테스트 데이터를 준비하고, 의사소통 체계를 둔다.
4. 테스트를 수행한다(보안 검토 이행).

## 결함 관리 (pp.71-76)

1. 테스트 보고서를 발행한다.
2. 지적 사항을 해결한다.
3. 결함 해결 사항을 보고한다.
4. 점검이 완료된 소스코드를 관리한다(버전, 재진단 결과).
5. 전반적인 보안 상황을 보고한다.
