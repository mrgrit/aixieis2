# 네트워크 보안 구현 준비 (학습 1-3)

## 설계 보완 (pp.37-38)

1. 가용성을 고려한 기본 네트워크(이중화)를 설계한다.
2. 서비스 요구에 맞게 장비·회선 용량을 설계한다.

## 일정 계획 (p.40)

전체 일정 → 세부 업무 단위별 일정.

## 환경 점검표

| 항목 | 점검 내용 |
|---|---|
| 전원 | 이중화 전원, 정격 전압·전류, UPS 배터리 상태·작동 시험 |
| 설치 공간·랙 | U 크기, 랙 마운트, 통풍·발열·공간 |
| 네트워크 연결성 | 업·다운링크 포트 수, VLAN, IP·게이트웨이 계획, 경로 |
| 케이블·포트 | 광·UTP 종류·길이, 패치패널 경로, 라벨링 |
| 관리 접근 | 초기 관리자 계정, 비밀번호 정책, 관리 IP 대역, SSH·HTTPS |
| 설계서·구성도 검증 | 장비 위치, 트래픽 경로, SPAN 포트, 정책 흐름 |
| 라이선스·펌웨어·SW 버전 | 시그니처 업데이트 가능 여부, VPN 사용자 라이선스 수 |

## 단계별 산출물

| 단계 | 산출물 예 |
|---|---|
| 준비 | 환경 점검표, IP·포트·VLAN 계획서, 접근 통제 정책 초안 |
| 설치 | 설치 결과서(랙·케이블 배선도), 기본 설정 백업 |
| 정책 적용 | 정책 적용 내역서(ACL·시그니처·VPN), 변경 요청서·승인 |
| 검증 | 시험 결과서, 오탐 검증 기록, 성능 측정표 |
