# 시스템 보안요구사항 정의 (학습 1-1)

## 절차

1. 시스템 보안 관련 법·제도 규정을 파악한다. (p.5)
2. 기업의 시스템 내역을 파악한다. (p.6) `asset_inventory`, `host_config`.
3. 기업의 시스템 보안 정책을 파악한다. (p.7) 보호 대상 자산(지적 정보 자산, 고객 정보, 중요·기밀 정보, 업무 환경 자산)과 정책 원칙. `policy_docs`.
4. 시스템 보안 절차서를 파악한다. (p.8) 적용 범위, 역할(정보 보안 책임자·관리자, 시스템 관리자·담당자), 설치 시 보안 검수, 접근제어, 침입 탐지.
5. 시스템 보안요구사항을 파악하고 명세한다. (pp.9-15)
   인증 → 접근 통제 → 로깅·감사 → 암호화 → 프라이버시 → 침해사고 예방·대응 → 요구사항 명세서 작성.

## 인증 요구사항 예 (시험 문항1 유형)

| 구분 | 요건 | 내용 |
|---|---|---|
| 계정 관리 | 기본 계정 | 설치 시 제공되는 기본 계정은 사용하지 않거나 비밀번호 변경·잠금 |
| 계정 관리 | 공용 계정 금지 | 여러 사용자가 함께 쓰는 계정 금지, 1인 1계정 |
| 계정 관리 | 주기적 검토 | 계정 정보가 최신 상태인지 정기 검토 |
| 계정 관리 | 개발·테스트 계정 | 운영 서버의 개발·테스트 계정 삭제 |
| 계정 관리 | 인사 변경 반영 | 이동·퇴직 시 권한 변경·삭제 절차 |
| 비밀번호 | 복잡성 | 길이·문자 종류 의무화 |
| 비밀번호 | 최초 변경 | 임시 비밀번호는 최초 사용 시 변경 강제 |
| 비밀번호 | 잠금 | 연속 실패 시 자동 잠금 |
| 비밀번호 | 재사용 제한 | 이전 비밀번호 일정 횟수 재사용 금지 |
| 비밀번호 | 유효 기간 | 주기적 변경 의무화 |
