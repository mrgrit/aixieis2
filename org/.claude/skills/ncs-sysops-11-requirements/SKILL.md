# 시스템 보안 솔루션 요구사항 분석 (학습 1-1)

## 요구사항 도출 (pp.5-7)

1. 정보보호 제도·정책·지침에서 시스템 보안 영역의 요구사항을 찾고 통제 수준을 정한다(`policy_docs`).
2. 기존 정보화 사업 담당자 인터뷰로 정보보호 현황, 사업 목적, 비즈니스 요구를 파악한다.
3. 보호 대상(정보 자산)을 도출한다(`asset_inventory`).
4. 보호 대상별 취약점과 위협을 분석한다(<표 1-2>).
5. 취약점·위협에 대응할 보안 요구사항을 도출한다(<표 1-3>).

## 솔루션 현황 파악 (pp.7-8)

1. 도입된 보안 솔루션 현황이 문서로 최신화돼 있는지 확인한다.
2. 솔루션의 **운영 주체**가 누구인지 점검한다.
3. 솔루션이 보호하려는 **자산**이 무엇인지 파악한다.
4. 보호 대상 자산의 **운영 주체**가 누구인지 점검한다.
5. 자산의 **알려진 취약점**을 파악하고 있는지 확인한다(`vuln_feed`, `package_inventory`).
