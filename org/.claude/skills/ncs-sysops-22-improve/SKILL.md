# 운영 개선 (학습 2-2)

## 취약점 진단과 개선 (p.39)

1. 중점 관리할 진단 대상을 고른다.
2. 개선 사항을 잘 드러낼 진단 항목을 정한다.
3. 영역별·유형별로 진단한다(`host_config`, `host_accounts`, `package_inventory`).
4. 진단 결과를 분석하고 개선한다(변경은 `change_prepare` kind=host).

## 위험 모니터링 (p.41, [그림 2-9])

1. 분기·반기 정기 점검으로 보안 규정 이행 상태를 점검한다.
2. 유사 시스템에 중요 취약점이 나오면 수시 점검과 대응을 한다(`vuln_feed`).
3. 위협·사고가 의심되면 시스템 로그를 수집·분석해 상태를 확인한다(`log_read` host·auth).
4. 사고가 나면 유입 경로를 파악하고 디지털 증거를 확보하는 포렌식 절차를 준비한다.
5. 정기·지속 모니터링으로 적정 수준 이상으로 커진 잠재 위험을 통제하고, 점검 결과를 전파한다.
