# 시스템 보안 설계 (학습 1-2)

## 개념 설계 (pp.21-24)

1. 시스템 보안의 개념적 설계를 한다.
2. 보안 프레임워크를 구성한다.
3. 정보시스템 보안 계층을 구성한다.
4. 정보보호 기술 영역을 구성한다(<표 1-22>).

| 기술 영역 | 설명 |
|---|---|
| 인증 | 접근 중요도에 따라 차별화된 인증 |
| 접근 통제 | 접근 필요성에 따라 권한 부여, 비인가 접근 제한 |
| 암호화 | 기밀 정보를 전송·저장 시 보호 |
| 로깅 및 감사 | 접근·처리 내역 보존으로 감사 추적성 확보 |
| 프라이버시 | 개인정보 유출·오남용 방지 |
| 침해사고 예방 및 대응 | 침입 탐지·차단·예방 |

5. 시스템 보안 대상을 정한다. (p.24)

## 상세 설계 (pp.25-36)

| 설계 항목 | 설계 내용 예 |
|---|---|
| 계정 관리 | ID 작성 기준, 검토·승인자, 인사 DB 연계, 매월 검토 |
| 패스워드 관리 | 작성 기준, 변경 주기, 메시지 |
| 인증·로그인 | 인증 방식, 로그인 실패 처리 |
| 세션 관리 | 세션 인증, 타임아웃, 중요 거래 재인증 |
| 접근 통제 | 인터페이스 최소화, 접근 최소화, 접근 통제 목록 |
| 권한 관리 | 최소 권한, 우선순위, 허용보다 거부 우선 |
| 로그 관리 | 인증·인가·계정 로그, 중앙·분산 기록 |
| 취약점 대비 | 주기적 패치, 담당자 지정 |

## 산출물

설계서: 항목별 설계 내용, 대응 요구사항 ID(1-1), 구현 시 검증 방법(2-2에서 쓸 시험 항목).
