# 시스템 보안 구현 검증 (학습 2-2)

## 시험 항목 (pp.71-80)

2-1에서 구현한 항목마다 '결함 여부'를 시험한다. 설정 파일 값뿐 아니라 실제 동작도 확인한다.

| 항목 | 시험 |
|---|---|
| root 원격 접속 | sshd 설정 값과 실제 root 원격 로그인 거부 |
| 불필요 계정 | 미사용·의심 계정, lp·uucp·nuucp 같은 기본 계정, 로그인 실패 기록 |
| 관리자 그룹 | root 그룹 구성원 최소화 |
| 패스워드 | 파일 보호, 잠금 임계값, 최소 길이, 최대·최소 사용 기간 |
| 세션 | 타임아웃 |
| 서비스 | NFS 접근 통제, Apache 상위 디렉터리 접근 금지 |
| 파일 권한 | passwd, shadow, services, hosts.lpd, cron 파일 |
| 로그 | 정기 검토·보고 체계, 로깅 설정 |
| DBMS | 기본 계정 비밀번호 변경, 원격 접속, 응용 계정 권한(DBA Role, Public 권한 취소) |
| 웹 | 도구 점검, SQL 인젝션, XSS 시험 |

DBMS 권한 시험 예(MySQL): `SHOW GRANTS FOR 'user'@'host';`로 권한을 보고,
`GRANT SELECT ON dbname.* TO 'user'@'host';`처럼 필요한 권한만 준다.
SQL 인젝션 시험 문자열 예: `' OR '1'='1`, `' OR 1=1 --`, `admin' --` (테스트 환경에서만).

## 결함 관리 (p.82)

1. 결함을 분야별·심각도별로 목록화한다.
2. 취합된 결함을 해결한다(요청서로 담당에게).
3. 시스템 보안 결함 관리 대장을 기록한다.
