# 네트워크 보안 구현 (학습 2-1)

## 절차 (pp.50-56)

1. 장비를 배치하고 기본 설정을 적용한다.
2. 네트워크 장비의 보안 항목을 설정한다.
3. 서버 네트워크 영역의 보안 장비·솔루션을 구성·설정한다.
4. 클라이언트 네트워크 영역의 보안 장비·솔루션을 구성·설정한다.
5. 보안 자산 관리 체계 운영 시스템, 형상 변경 보안성 승인 시스템을 구성한다.
6. 장비 계정 보안(기본 계정, 비밀번호, 권한 등급)과 장비 접근 보안(관리 IP 제한, 원격 접속 암호화, 유휴 종료)을 설정한다.

구현은 `change_prepare`(kind=fw-design)로 요청서를 쓰고 승인 후 운영 담당(`nw-sec-ops`)이 적용한다.

## 연동 검증 절차

| 단계 | 점검 |
|---|---|
| 1 방화벽 정책 | 정책 반영, 로그 포맷(시간·출발지·목적지·포트·동작), 허용·차단 시험 트래픽으로 로그 발생, 전송 경로 |
| 2 IDS 규칙 | 규칙 활성화, 로그 필드(시그니처 ID·심각도·출발지·목적지), 무해한 탐지 시험(웹 스캔·Ping sweep), SIEM 전송 방식(syslog 등) |
| 3 SIEM | 수집 여부, 전송 주기, 필드 매핑, 탐지→경보 흐름, 상관분석 규칙(방화벽 차단 + IDS 탐지) |
| 4 보고·승인 | 검증 결과 보고서(절차·결과·스크린샷·이슈), 문제 조치 확인, 보안운영팀장 승인 |
