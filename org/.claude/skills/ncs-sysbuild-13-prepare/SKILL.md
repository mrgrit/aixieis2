# 시스템 보안 구현 준비 (학습 1-3)

## 구현 환경 (pp.39-40)

| 환경 | 내용 |
|---|---|
| 관리적 | 보안 정책, 보안 규정·절차서, 보안 조직·인원 |
| 기술적 | 시스템 보안 솔루션, 패키지 |
| 물리적 | IDC, 보안 통제 공간, 잠금장치, 출입 통제 장비 |

## 구현 계획 (pp.40-41)

추진 목표 설정 → 추진 범위·수행 업무 세분화 → 조직·역할 정의 → 추진 일정 수립.

## 검증 도구 준비

| 용도 | 예 |
|---|---|
| Windows 보안 설정 확인 | 보안 설정 점검 도구 |
| 서버 자체 포트 스캔(모르는 사이 열린 포트 확인) | nmap 등 포트 스캐너 |
| 웹 취약점 점검(OWASP Top 10) | 웹 취약점 스캐너 |

랩에서는 설정 조회(`host_config`)와 계정 조회(`host_accounts`)가 기본 검증 수단이다.
