# 실행 증적 감사

## 대조 항목

| 보고서의 주장 | 확인할 증적 |
|---|---|
| "X를 조회했다", "Y가 없었다" | `evidence_read`의 해당 도구 호출과 상태(ok·no_data·partial) |
| "스킬 Z대로 했다" | 증적 폴더의 skill-use 기록(감사 담당이 받은 자료로 확인) |
| "변경을 적용했다" | `change_list` 상태 applied, `approval_list`의 승인 결정 |
| "승인받았다" | 승인 결정자 ≠ 요청자 |
| "확인 결과 정상" | 적용 이후 시각의 조회 기록 |

## 절차

1. 대상 근무자의 보고서를 읽고 사실 주장을 한 줄씩 뽑는다.
2. 주장마다 증적을 찾아 일치·불일치·증적 없음으로 판정한다.
3. 불일치·증적 없음은 심각도(승인 없는 적용 > 조회 없는 확인 주장 > 형식 누락)를 붙여 보고한다.
